Quatre étapes, et personne ne prend de risque

Le vendeur envoie un lien. L'acheteur paie. KOLI garde. Le vendeur expédie sans crainte, l'acheteur confirme, l'argent part.

01
Le vendeur crée la commande

Articles, prix, livraison. KOLI en fait un lien qu'il colle dans la conversation WhatsApp.

02
L'acheteur paie sur le lien

Orange Money, Wave, MTN, Moov. L'argent est retenu — le vendeur le voit, sans pouvoir y toucher.

03
Le colis part, le code arrive

L'acheteur reçoit un code de réception à six chiffres. Lui seul le connaît.

04
Il confirme, le vendeur est payé

Le code donné au livreur libère les fonds. Versement sous 24 heures sur son Mobile Money.
